# InventorySyncCore

Private internal inventory tool for the Etsy shop Kova3DArts.

## Purpose
This application is used only by the shop owner to keep listing quantities aligned with internal production records.

## How it works
1. Authenticates using Etsy OAuth
2. Retrieves listings from the shop
3. Reads listing ID, SKU, and quantity
4. Compares with internal production data
5. Updates inventory only when necessary

## Data Used
- Listing ID
- SKU
- Quantity

## Restrictions
- No access to other sellers
- No scraping
- No analytics or aggregation
- Internal use only
